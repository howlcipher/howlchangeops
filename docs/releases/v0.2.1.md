# HowlChangeOps v0.2.1

## Model B Protected Authority & Replay Ledger
Implements the Model B protected authority foundation:
- Safe keygen and enrollment tooling (`authority init`, `authority keygen`, `authority enroll`, `authority revoke`).
- Owner-facing operation review and Ed25519 cryptographic signing (`authority review`, `authority sign`).
- Protected executor with SQLite WAL replay ledger (`authority execute`).
- Exact parameter and action binding to prevent replay and tampering.
- Verified against all 9 Model B acceptance criteria.
