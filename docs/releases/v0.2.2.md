# HowlChangeOps v0.2.2

## Model B Protected Authority: Native CGO Runtime & Adapter Hardening

Release v0.2.2 addresses critical runtime packaging defects in v0.2.1 and hardens protected action adapter semantics:

### 1. Native CGO SQLite Packaging
- Configured GitHub Actions release pipeline with `CGO_ENABLED=1` on supported `linux/amd64` runners.
- Repaired broken `static_mock.go` fallback where non-CGO compilation previously caused `authority init` and replay ledger operations to fail at runtime.
- Added post-compilation packaging verification step (`authority keygen`) in the release workflow.
- Enforced platform policy: explicit runtime diagnostics (`ErrUnavailable`) on unsupported or non-CGO platforms (Windows POSIX gap, non-CGO stubs). Official release binaries are scoped to `linux/amd64`.

### 2. Protected Action Adapter Correctness
- `create_release_candidate`: Enforces explicit target repository path resolution, validates Git repository integrity via `git rev-parse --git-dir`, verifies commit existence, verifies tag creation, implements idempotent return on identical commit tags, and rejects conflicting tags.
- `rollback_release_candidate`: Validates target repository and revision prefix before tag deletion, does not suppress Git command errors, verifies tag removal, and returns `ALREADY_RECONCILED` idempotently if tag is already absent.
- `record_release_ready`: Clarified semantics as an owner-authorized decision record; immutably binds target, revision, decision ID, and evidence digest into signed receipts.

### 3. Acceptance Verification
- Full suite of 10 packaged-runtime acceptance criteria verified against actual release archive.
